The adaptation pins pack metadata to Herps' Minecraft 26.3 resource format 97.1.
It retains the 14 supplied minecraft leaf blockstate definitions, canonical leaf
item models and their exact required parents/textures. Included source asset bytes
are unchanged. Unused
models and overrides for unsupported Java mods are omitted. Such overrides do
not implement those mods or register their blocks in Herps.

This is an optional visual resource pack, not a shader, .hmod or Java mod.
No game engine, block IDs, drops, collisions, profiles or saves are changed.
Visual rendering, performance and native interactive acceptance need real tests.
