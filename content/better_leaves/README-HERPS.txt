HERPS BETTER LEAVES 9.6 — MINECRAFT 26.3

This is an optional resource pack. Use your existing Herps Launcher installation.
It needs no Java mod loader, OptiFine, new launcher installer or Rust tools.
RLCraft-style development is paused; existing content and worlds are preserved.

1. Start with a disposable test profile and back up any worlds you value.
2. In Herps Launcher select that profile. Open Settings, then
   "Open game data and saves". Close running games before copying files.
3. Create a resourcepacks folder inside that profile's game folder if needed.
4. Put Herps-Better-Leaves-9.6-MC26.3.zip in resourcepacks. Keep this inner ZIP
   zipped. If downloaded through GitHub Actions, extract its outer artifact ZIP
   first to find the actual pack ZIP and checksum file.
5. Start the game using ordinary PLAY. Open the game's Options -> Resource Packs,
   select Herps Better Leaves and apply/finish the selection. Wait for reload.
6. Test leaves with cutout/transparent leaves enabled in Video Settings.
   Exact menu wording and real rendering are not yet manually verified.

Check oak/birch/spruce and other available leaf types for fuller foliage,
correct colours, transparent edges and missing-texture squares. Compare the same
scene with the pack disabled and note FPS. Models extend outside the block;
normal drops and collision shapes should remain unchanged. Save/quit, close and
restart both apps, then check the selected pack and world again.

To undo: deselect this pack in the game's Resource Packs menu and let it reload.
After closing the game, its ZIP can be moved out of resourcepacks. Leave all
other files and packs in place. Do not delete options.txt, saves or mods.

If it fails: record the launcher/game version, profile, enabled packs, graphics
settings, GPU/driver and exact leaf type. Disable other visual packs for a separate
disposable trial. Collect logs through the launcher, removing account details,
tokens and personal paths. Do not upload copyrighted game resources or valuable saves.

No whole-RLCraft/FunCraft, Java mod or shader compatibility is claimed. Additional
pack textures can conflict; the supplied Lite-style leaves replace leaf textures.
Native visual/gameplay/performance testing on Windows and macOS remains NOT RUN
until separately recorded. Preserve Motschen's accompanying MIT LICENSE/NOTICE.
