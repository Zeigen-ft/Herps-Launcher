# Herspers Minecraft

A new project targeting macOS, focused on rebuilding a Minecraft Bedrock experience.

## Project status

The repository has been initialized. The engine, client, build system, and implementation scope have not yet been selected or implemented.

## Development environment

The cloud workspace runs Linux. Cross-platform components can be developed here once the toolchain is selected. Building and testing the macOS application requires a Mac with the appropriate Apple development tools.
