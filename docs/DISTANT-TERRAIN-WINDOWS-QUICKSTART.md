# Try native Explored Terrain LOD on Windows

This is a client graphics feature, not a JAR or `.hmod` package. Your server
does not need a new LOD mod or streaming service. Only terrain this client has
received can appear in the distant view. Use a disposable profile/world first.

**[Download the Windows LOD candidate](https://github.com/Zeigen-ft/Herps-Launcher/actions/runs/44102123363/artifacts/14339754271)**
from successful run **44102123363**, source **44b21a8**. GitHub may ask you to
sign in. Choose **Herps-Launcher-0.1.0-Windows-x86_64**, not a verification-log
or native-content artifact. The download contains Setup and a portable ZIP.
The [candidate receipt and exact SHA-256 hashes](DISTANT-TERRAIN-WINDOWS-CANDIDATE.md)
were independently checked. The earlier Stage 1 source/CPU ZIP contains logs,
not the launcher.

## Open the new game build

1. Download the Windows candidate's outer GitHub artifact ZIP. Extract it.
2. For the first test, use the **portable ZIP inside it**. Extract into a new,
   short folder such as `C:\Herps-LOD-Test`. Keep your old installation,
   profiles, prepared resources, worlds and backups. Compare the portable ZIP's
   SHA-256 with the included `SHA256SUMS` before extracting it.
3. Close the old game and launcher. Open `Herps Launcher.exe` in the newly
   extracted `Herps Launcher` folder.
4. Open **Settings → Switch / update game installation…**. Select the new
   candidate's **`game\Herspers-Minecraft`** folder. For the example above this
   is normally `C:\Herps-LOD-Test\Herps Launcher\game\Herspers-Minecraft`.
   Click **Validate installation**. Check the version/source details.
5. The launcher preserves a manually selected old game installation across
   updates. If you skip the previous step, you may launch the old game and
   never see the new LOD option.
6. On **Home**, choose **+ New profile** and name it `lod_test`. Use the normal
   legitimate resource preparation/validation if prompted; this feature does
   not change that process. Click **PLAY**, then create/open a disposable world.
   For an existing test server, use the launcher's **Multiplayer** page and
   keep your intended player name unchanged.

If using the Setup installer instead, close the old game and launcher first;
stop any native host running from that installation with `stop` before its
shared binaries are replaced. Keep user data when updating/uninstalling. The
installed bundled game is normally under
`%LOCALAPPDATA%\Programs\Herps Launcher\game\Herspers-Minecraft`.
The portable option avoids replacing your current installation for this test.
It still uses the launcher's existing settings/data location. Switching the
game installation changes that shared selection; choose your old installation
again if you later return to the old launcher.

## Turn on the feature

In the game, open **Options… → Horizon Settings → Advanced Graphics…**.
**Options… → Video Settings… → Advanced Graphics…** is another route.

Set:

| Option | Starting value |
| --- | --- |
| Explored Terrain LOD | **On** |
| Older LOD Distance option | **Off** |
| Near Distance (normal Render Distance) | **4–8 chunks** |
| Explored LOD Radius | **64 chunks** |
| LOD Memory | **64 MiB** |
| LOD Disk Cache | **512 MiB** |
| LOD Workers | **1** |

Walk around to receive terrain. Move far enough away that an explored area
leaves the near distance, then look back from a hill or clear view. It should
be eligible for the coarse distant view. Previously unseen terrain is not
generated by this mode. Give the background worker time to catch up.

If **Explored Terrain LOD** is missing, check that you switched to the new
game installation and opened **Advanced Graphics**, not the simple page.
Do not import the Distant Horizons Java JAR into the launcher to enable this.

## What to report

Record the candidate/run, Windows/GPU, settings and the area you explored.
Check distant terrain, move the near/far boundary, close/reopen the world and
verify your disposable world/inventory. Report PASS/FAIL/NOT RUN for each
case in the [full checklist](DISTANT-TERRAIN-MANUAL.md). Screenshots can show
visual issues; omit private server addresses and personal information.

Automated build/install checks are separate from physical gameplay. This
candidate does not establish that transitions, performance, save/restart or
all platforms are accepted. Do not test first on your only valuable save.
