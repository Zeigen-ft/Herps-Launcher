## API profile keys

| Profile | Meaning / source-review worklist |
| --- | --- |
| **RECIPE** | Small data recipe candidate: Forge item registry, OreDictionary and legacy recipe JSON; adapt one explicitly scoped recipe to native content API 0.2 |
| **LIB** | Library/API dependency: FML lifecycle, JVM libraries and/or Forge APIs consumed by dependants; replace only the API surface a selected native feature needs |
| **SCRIPT** | Scripting/quest integration: ZenScript/CraftTweaker interfaces, Forge recipes/loot/registries and referenced mod APIs; translate selected declarative behavior, never run the scripts |
| **UI** | Client UI/inventory information: Forge client events, GUI/container/item-tooltip APIs and often packets/inventory semantics; native source rewrite needs matching authoritative hooks |
| **WORLD** | World generation/structures: Forge world/biome/chunk/structure APIs, persistent modded IDs and generators; audit native worldgen coverage and migration separately |
| **ENTITY** | Entities/AI/transport: Forge entity registration, AI/attributes/spawning, models/animation, interaction packets and persistent entity data |
| **PLAYER** | Survival/combat/player state: Forge player/living events, capabilities, damage/effects/attributes, equipment and saved/NBT/network state; server authority and duplication safety must be proved |
| **PATCH** | Optimization/fix/bootstrap: Old Minecraft/Forge internals, events and/or LaunchWrapper/ASM/Mixin hooks; do not transplant patches or assume an equivalent native bug |
| **VISUAL** | Rendering/audio/environment: Forge rendering/sound/client events, old GL/model/resource assumptions and sometimes animation/physics; native renderer/audio rewrite needs measured behavior |
| **RULES** | Server rules/spawn/loot: Forge spawn/living/tick/world events, loot tables, attributes and/or commands; preserve permissions, player data and server authority |
| **CONTENT** | Mixed blocks/items and gameplay: Forge registries/recipes, block/item behavior, tile entities/containers, rendering, drops and saved state; decompose the feature set first |
| **RESOURCE** | Legacy asset formats, target-mod IDs and renderer features; rights and actual native output validation required |
